# 后端全栈学习笔记生成计划

## 产出物

在 `docs/` 目录下生成一份 Markdown 学习笔记文件：`docs/backend-learning-notes.md`

## 笔记大纲（共10章）

### 第1章：FastAPI 应用结构与启动流程
- FastAPI 是什么（对比前端的 Express/Koa）
- 应用入口 `main.py` 解析：中间件、路由注册、启动钩子
- CORS 中间件原理（对接前端跨域知识）
- API 版本前缀设计 `/api/v1`

### 第2章：配置管理（Pydantic Settings）
- 环境变量 vs `.env` 文件 vs 代码默认值的优先级
- `BaseSettings` 自动加载配置的机制
- 单例模式 `@lru_cache` 的作用
- 关键配置项说明表

### 第3章：数据库与 ORM（SQLAlchemy）
- 关系型数据库基础（对比前端的 localStorage/IndexedDB）
- 连接池概念与 `pool_pre_ping`
- ORM 映射：Python 类 = 数据库表
- 五个核心模型详解：User、ImageAsset、AnalysisTask、AnalysisResult、AnalysisFeature
- 外键关系、级联删除、索引设计
- UUID vs 自增 ID 的选择

### 第4章：认证与安全（JWT + bcrypt）
- 密码哈希原理（为什么不存明文）
- JWT 双 Token 设计：access_token（短期）+ refresh_token（长期）
- Token 生成、验证、过期处理的完整流程
- 对比前端 localStorage 存储 token 的实践

### 第5章：依赖注入模式
- FastAPI 的 `Depends()` 机制（对比 Vue 的 provide/inject）
- 数据库会话注入 `get_db()`
- 认证守卫 `get_current_user()` 链式依赖
- Generator 模式的资源管理（自动关闭连接）

### 第6章：API 路由与 Pydantic Schema
- 路由定义与 HTTP 方法映射
- Pydantic 请求体验证（对比前端表单验证）
- 响应模型 `response_model` 自动序列化
- 文件上传 `UploadFile` 的处理流程
- 自动生成 OpenAPI 文档

### 第7章：异步任务处理（Celery + Redis）
- 为什么需要异步任务（对比前端的 Web Worker）
- 消息队列概念：生产者/消费者模式
- Celery 配置与任务定义
- 任务状态流转：PENDING -> RUNNING -> SUCCEEDED/FAILED
- 前端轮询策略配合

### 第8章：服务层四段式管道设计
- 分层架构思想：Router -> Service -> Infrastructure
- CV 层：图像特征提取（亮度、对比度、主体位置）
- LLM 层：生成自然语言建议和评分
- Rules 层：规划可执行编辑动作（裁剪/曝光/白平衡参数）
- Composer 层：组装最终标准化结果 JSON
- 对象存储 MinIO/S3：upload/download/presigned URL

### 第9章：Docker 容器化与部署
- Docker 基础概念（镜像、容器、Dockerfile）
- docker-compose 多服务编排（API + Worker + PostgreSQL + Redis + MinIO + Nginx）
- 开发环境 vs 生产环境配置差异
- Nginx 反向代理：路由分发、静态文件服务
- 部署脚本 `deploy.sh` 流程

### 第10章：数据契约（JSON Schema）
- 前后端数据契约的意义
- `analysis-result.schema.json` 结构解析
- `annotation.schema.json` 标注数据格式
- `edit-action.schema.json` 编辑动作格式

## 笔记特色

- 每个概念都会与前端已有知识做类比对照
- 包含项目中的实际代码片段和注释
- 关键流程配有 ASCII 流程图
- 附带「面试可能问到的点」小贴士
